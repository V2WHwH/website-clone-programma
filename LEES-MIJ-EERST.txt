HereWeHolo — complete applicatie
==================================

Dit is alles: de touch-software, de Windows-app, het beheerplatform,
de handleiding en het bewegingssysteem. Er is niets anders nodig.


═══════════════════════════════════════════════════════════════════
 1. IK WIL GEWOON BEGINNEN
═══════════════════════════════════════════════════════════════════

  studio/index.html          ← dubbelklik dit bestand

Dat is de holobox-software. Geen installatie, geen internet, geen
server. Hij draait in Chrome of Edge en bewaart alles in de browser
van die computer.

Op Windows kun je ook de meegeleverde starters gebruiken:

  studio/Start Holobox.bat              schermvullend (kiosk)
  studio/Start Holobox (venster).bat    in een venster, om te bouwen

Weet je niet waar je moet klikken? Open dan eerst:

  docs/handleiding/index.html           HET BEDIENINGSBOEK


═══════════════════════════════════════════════════════════════════
 2. DE WINDOWS-APP (.exe)
═══════════════════════════════════════════════════════════════════

In de download HereWeHolo-Compleet-*.zip zit de installer erbij:

  windows-app/HereWeHolo-Player-Setup-*.exe    ← dubbelklikken

Haal je alleen de broncode op, dan staat de installer op de
release-pagina, samen met de portable versie (uitpakken en starten):

  https://github.com/V2WHwH/website-clone-programma/releases

Gebruik de Windows-app als de box:
  - schermvullend moet opstarten en zichzelf herstellen na een crash;
  - geluid meteen moet laten horen (browsers dempen tot de eerste
    aanraking, de app niet);
  - 24/7 draait en de watchdog nodig heeft.

Zelf bouwen kan ook, uit de map desktop/ :

    cd desktop
    npm install
    npm run dist        → desktop/release/

Dat vereist Windows. Via GitHub Actions gebeurt het automatisch:
.github/workflows/desktop-build.yml bouwt en publiceert de release.


═══════════════════════════════════════════════════════════════════
 3. HET BEHEERPLATFORM (meerdere boxen op afstand)
═══════════════════════════════════════════════════════════════════

Alleen nodig als je meer dan één holobox centraal wilt beheren.

    npm install
    cp .env.example .env        en vul ADMIN_PASSWORD in
    cp data/db.example.json data/db.json
    npm start                   → http://localhost:8080/admin

Wat het je geeft: mappen en uploads, playlists, live streams, een
device-dashboard met online-status en "speelt nu", en commando's op
afstand (identificeren, verversen, herstarten, scherm zwart, volume,
schermafdruk opvragen, een ontwerp publiceren).

Koppelen doe je in de touch-software onder "Beheer & device":
serveradres + device-key uit het beheerpaneel.

═══════════════════════════════════════════════════════════════════
 OM TE WETEN
═══════════════════════════════════════════════════════════════════

- Je ontwerp staat in de browseropslag van die ene computer, onder dat
  ene profiel. Exporteer na elke sessie via Beheer & device →
  "Ontwerp exporteren (.json)". Media neem je apart mee.

- data/db.example.json bevat geen devices: je voegt je eigen boxen toe
  in het beheerpaneel. De sleutel van de testbox is er bewust uit.

- Zonder code-signing-certificaat waarschuwt Windows Defender bij de
  .exe voor een onbekende uitgever. Kies "Meer informatie" → "Toch
  uitvoeren", of controleer SHA256SUMS.txt uit de release.

- De koppen van de handleiding halen hun lettertype bij Google Fonts.
  Zonder internet valt hij terug op systeemletters; alles blijft
  leesbaar.
