# Feature proposals — phase 2+

Three differentiating features, specified now so the architecture can anticipate them, **built only
after the M8 acceptance scenario is stable** (per `MILESTONES.md` — building them earlier slows the
project down, it does not speed it up).

| # | Feature | One-liner | Attacks |
|---|---|---|---|
| [F1](F1-BACKGROUND-REMOVAL.md) | **Studio Matte** — AI background removal | Any room becomes a studio; no physical cyclorama needed | The single biggest real-world adoption blocker |
| [F2](F2-LIVE-TRANSLATION.md) | **Voice Bridge** — live translation | Present in English, Amsterdam hears Dutch; subtitles or translated voice | The language barrier of an international telepresence product |
| [F3](F3-WALKUP-PRESENCE.md) | **Walk-up** — presence detection & instant call | The Holobox greets a visitor and calls an available colleague | Boxes idle 95% of the time; passive display → two-way concierge |

UX for all three is designed in `design/mockups/index.html` §07 and in the Figma file
(page *🔮 07 Concepts*). Complex options carry an **info dot (ⓘ)** with a short, sharp explanation —
a pattern introduced here and retrofitted onto existing complex options (quality Auto, edge route,
echo cancellation).

Status: **Proposed** — sequencing decision (which one first, post-M8) is Desmond's.
